# Manuscrito e notebook ilustrativo

Exemplo com dados sintéticos, sem resultado científico real. A AUC mostrada é calculada da curva ilustrativa. O requirements.txt é um manifesto de exemplo sem lock e não garante reprodução de ambiente. Confira dependências, engine e estratégia Binder antes de executar comandos de configuração. Binder/MECA são opcionais conforme a entrega; não publique como efeito de uma edição local.
