# Manuscrito e notebook ilustrativo

Exemplo com dados sintéticos, sem resultado científico real. A AUC mostrada é calculada da curva ilustrativa. O requirements.txt fixa numpy 2.5.4, que pede Python 3.12 ou mais novo, e matplotlib 3.11.2, conferidos no PyPI em 7 de novembro de 2026. O runtime.txt pede Python 3.12 ao Binder. Nenhum dos dois trava as dependências transitivas nem garante reprodução de ambiente. Confira dependências, engine e estratégia Binder antes de executar comandos de configuração. Binder/MECA são opcionais conforme a entrega; não publique como efeito de uma edição local.
