# Manuscrito e notebook ilustrativo

Exemplo com dados sintéticos, sem resultado científico real. A AUC mostrada é calculada da curva ilustrativa. O requirements.txt fixa as versões diretas (numpy 2.5.4 e matplotlib 3.11.2, conferidas no PyPI em 7 de novembro de 2026, que pedem Python 3.12 ou mais novo), mas não trava as dependências transitivas nem garante reprodução de ambiente. Confira dependências, engine e estratégia Binder antes de executar comandos de configuração. Binder/MECA são opcionais conforme a entrega; não publique como efeito de uma edição local.
