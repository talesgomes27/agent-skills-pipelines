# Diagnóstico sem rede

Use `python3 <raiz-da-skill>/scripts/offline_probe.py` para localizar Quarto, metadados locais de versão e arquivos de engines no PATH ou no bundle instalado. `--quarto <caminho>` seleciona um executável sem executá-lo. O inventário não inicia subprocessos, consulta servidores ou instala componentes. Metadados devem ser arquivo regular, com leitura limitada/não bloqueante; symlinks de versão ou bundle fora do prefixo são rejeitados. `version_metadata` identifica a fonte local; `execution_verified:false` e `render_verified:false` separam presença de execução/render. Exit 0 significa inventário com arquivo Quarto encontrado; exit 2 significa arquivo não encontrado. `execution_verified:false` e versões desconhecidas não comprovam runtime, render ou conformidade do documento. Layouts de instalação diferentes podem não expor metadados/Typst embutido.

No Quarto 1.10.19 observado, `quarto tools` chama `loadTools`, consulta `latestRelease` e acessa a API GitHub de releases do TinyTeX. Isso é consulta remota de versão, não inventário estritamente local. Instalação (`quarto install`/subcomandos equivalentes) acrescenta download e escrita e exige autorização própria. Erro de DNS ou conexão falha ainda registra uma tentativa. Não use listagem de tools/checks online como fallback para esse inventário.

Para confirmar execução ou render sem rede, revise células/filtros/hooks/recursos e use executor com fonte/políticas somente leitura, cópia de trabalho e HOME/cache temporários, rede efetivamente bloqueada e observador de tentativas externo ao processo. Pré-valide escrita negada na fonte, escrita permitida no temporário e conexão IPv4/IPv6 direta negada e registrada, sem depender de DNS. Se essa capacidade faltar, entregue inventário e check pendente; não transforme a restrição em autorização de rede.

Com contenção validada, versões locais e renders mínimos de HTML/Typst podem ser verificados. Fontes, pacotes, imagens, extensões e engines podem tentar downloads; qualquer tentativa mantém o check de segurança reprovado mesmo quando bloqueada. Presença de PDF ou HTML não substitui inspeção do output. O doctor existente e `--render-smoke` continuam disponíveis para execução autorizada; não são sandbox de rede.
