# relatorios-v1 (fixture sintética)

Serviço antigo que gera PDFs de relatórios. Roda num servidor próprio com Docker Compose, em `relatorios.exemplo.invalid`.
O banco `relatorios_v1` guarda os relatórios gerados desde 2019. Um cron no mesmo servidor gera o fechamento mensal.
O relatorios-v2 substituiu a tela do usuário em 2026-06.
