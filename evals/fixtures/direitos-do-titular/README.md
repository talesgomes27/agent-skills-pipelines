# Loja (fixture sintética)

Banco PostgreSQL da loja; `schema.sql` tem o esquema. Pessoas e dados fictícios.
As notas fiscais emitidas ficam em `notas_fiscais` e o contador pede que sejam guardadas por cinco anos.
Os dados de entrega são enviados à transportadora RapidoLog.
Há backup diário do banco, guardado por 90 dias.
