# Amostra exportada do DataJud

Amostra sintética para teste, no formato de uma exportação da API Pública do DataJud para o TJPA. Os números de processo são fictícios. `data_baixa_definitiva` vazia significa processo ainda em curso na data da exportação, 2026-10-31. Os números têm o formato e o dígito válidos para o TJPA (8.14) e podem coincidir com processos reais por acaso: não os consulte em sistemas do tribunal.
