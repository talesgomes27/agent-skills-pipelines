# Planilha do escritório e exportação do tribunal

Dados sintéticos para teste: clientes e números de processo fictícios, alguns com máscara, alguns sem e alguns com o dígito verificador errado de propósito. Os números têm o formato e o dígito válidos para o TJPA (8.14) e podem coincidir com processos reais por acaso: não os consulte em sistemas do tribunal.
